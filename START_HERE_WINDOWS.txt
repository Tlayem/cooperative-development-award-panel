START HERE (Windows) - Cooperative Development Award Panel, draft v1.0.0

The checklist item "Reproduce" asks you to rebuild everything from your own
USAspending download and check that you get the same numbers.

1. Right-click this zip -> Extract All. Open the extracted folder
   "cooperative-development-award-panel".

2. Copy BOTH USAspending zips from Downloads into this folder, next to run_all.bat:
      PrimeAwardSummariesAndTransactions_2026-11-13_H20M44S46297510.zip   (10.771 + 10.871)
      the 10.352 Transactions zip you downloaded                         (corrections, ruling R14)
   (If this folder has no zips, run_all.bat uses every Prime*.zip in Downloads.)

3. Double-click run_all.bat.
   - If Windows shows "Windows protected your PC" or a security warning, click "More info" -> "Run anyway" / "Run".
   - If it says Python was not found, install Python from python.org, tick
     "Add python.exe to PATH" on the first screen, then double-click run_all.bat again.

4. When the black window says Done, compare data\processed\qa_report.txt with
   docs\qa_report_REFERENCE.txt. Both should show 4,728 raw rows, 1,843 awards,
   89 other-listing corrections, 1,585 new awards, $286.07m and QA failures: 0.

5. Tick the first line of docs\VERIFY_CHECKLIST.md and carry on with the rest.

The folder data\raw\usaspending starts empty on purpose. Your download fills it.
